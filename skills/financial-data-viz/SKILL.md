# Financial Data Visualization

The report should communicate financial information visually.

Tables are supporting material, not the primary visual language.

## Preferred visualizations

Use:

- KPI cards for headline metrics
- line charts for trends
- bar charts for comparisons
- stacked bars for composition over time
- donut/pie charts only for small part-to-whole datasets
- sparklines for compact trend indicators

## Recommended charts

Consider:

1. Net worth over time
2. Assets vs liabilities
3. Income vs expenses
4. Monthly net cash flow
5. Spending by category
6. Income composition
7. Account balances
8. Asset/liability composition
9. Debt trend
10. Investment trend

Only create charts that communicate something useful.

## Large account sets

There may be 20+ accounts.

Do not use a giant pie chart containing every account.

Instead use:

- horizontal bar charts
- account-type grouping
- paginated account tables
- compact account cards
- top-level distribution charts

The detailed account section must still contain EVERY eligible account.

## Readability

Never use tiny labels.

Never create charts with overlapping labels.

Never sacrifice readability to fit more charts on a page.
