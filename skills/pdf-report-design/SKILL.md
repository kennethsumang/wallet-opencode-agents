# PDF Report Design

Design the report as a premium financial publication.

## Design language

Use a Material UI-inspired system:

- deep indigo / blue primary
- teal/cyan secondary
- restrained semantic green
- restrained semantic red
- slate neutrals
- white/light backgrounds

Use color consistently.

## Layout

Use:

- strong cover
- clear section hierarchy
- KPI cards
- generous whitespace
- consistent grid
- consistent margins
- clear typography
- subtle cards/elevation
- restrained rounded corners
- page numbers

## Information hierarchy

Every major page should have:

1. clear title
2. short contextual description
3. primary visual
4. concise interpretation
5. supporting detail where necessary

Avoid walls of text.

Avoid table-heavy layouts.

## Illustrations

Use tasteful financial illustrations for:

- cover
- major section dividers
- selected conceptual explanations

Illustrations should remain secondary to the data.

## Tables

Use tables when detailed reference information is useful.

Especially use tables for:

- complete account inventory
- methodology
- detailed breakdowns

But do not turn the entire report into tables.

## Typography

Prioritize legibility.

Never make body text or chart labels tiny.

If content does not fit, create another page.

## Page quality

Avoid:

- orphan headings
- broken tables
- clipped text
- overlapping charts
- awkward page breaks
- excessive empty space
- dense walls of information
